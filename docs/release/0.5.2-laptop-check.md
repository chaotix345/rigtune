# RigTune 0.5.2: laptop check (about 15 minutes)

For Charlie's Lenovo IdeaPad Pro 5i (Core Ultra, Intel Arc integrated, 120 Hz OLED, Windows 11, Modrinth App), before HQ tags 0.5.2. It checks the 0.5.2 changes CI can't see: your screen and GUI scale, your launcher, and Distant Horizons on real hardware.

**The test jar:** HQ puts the release dry run's jars in a folder and sends you its path. Use `rigtune-0.5.2+mc26.2.jar` from it. Use a new throwaway instance, so nothing here touches your real one.

Each step says what to do and what you should see. Write down any step that fails and carry on; the last section says what to send back.

1. **Set up.** In the Modrinth App, create a new instance: Fabric, Minecraft 26.2. In its Content tab, add **Fabric API**, **Sodium** and **Distant Horizons**. Press **Open folder**, open `mods`, and copy `rigtune-0.5.2+mc26.2.jar` from HQ's folder into it. Launch the instance.
   *Pass:* the game reaches the title screen with a **RigTune** button.

2. **First run and the list.** Press **RigTune**. Leave Minecraft's GUI scale on Auto.
   *Pass:* the header isn't cut off mid-word: either the tier badge has its own line, or hovering the cut line shows a tooltip that wraps inside the screen. The list shows at least three rows. It includes **Distant Horizons: Auto Updater: On → Off**, ticked, with a reason about your launcher.

3. **Apply and restart.** Press **Apply selected**. Read the first-Apply guide if it opens, then quit the game and start it again from the app.
   *Pass:* the title screen shows **RigTune applied N change(s)**. N is about the number of rows you applied, not double. In RigTune, the Auto Updater row is gone.

4. **Sodium's Video Settings.** Options → Video Settings.
   *Pass:* the RigTune button sits above Sodium's Undo / Apply / Done buttons, not over the page list on the left. If Sodium's donation prompt opens, close it: the button then moves there.

5. **Profiles, back and forth.** RigTune → Tools… → Profiles…: switch to **Max FPS**. Go back to the RigTune screen.
   *Pass:* **Max Framerate: Unlimited → 120** (if listed) is **unticked**, and its reason ends "Your Max FPS profile sets this on purpose…".
   Then switch to **Quality**, then to **My settings**. Look at the RigTune screen.
   *Pass:* no **Discard pending** button. Quit and start the game again.
   *Pass:* **no** "RigTune applied … change(s)" toast this time.

6. **One Tune benchmark.** Tools… → Benchmark… → Scene: **Benchmark world** → **Tune settings**. It takes about 3 minutes; don't touch anything until the result screen shows. Press **Keep current**, then open RigTune again.
   *Pass:* the run finishes with a result screen. If it says your render distance "missed the target by 5% or less … RigTune doesn't suggest lowering it", that's the new wording. Back on the RigTune screen, there's **no** new "Max Framerate: 260 → …" row and no render distance row that wasn't there before the run.

7. **Try it with Distant Horizons.** Create a new singleplayer world (Distant Horizons generates terrain in it). In RigTune, press **Preview**, tick only **Simulation Distance** (or any one setting it offers), and press **Try it (measured)**. Follow the screen.
   *Pass:* either a verdict (Better / Worse / No clear change), or "No verdict … Let Distant Horizons finish generating first (its Show Generation Progress option shows when it's done), then try it again". It must **not** say "Try it again for a verdict" with Distant Horizons generating.

8. **Stutter Doctor.** Tools… → Stutter Doctor… → **Start**. Fly into new terrain in that world for about 3 minutes, then open Stutter Doctor again.
   *Pass:* percentages read like "59%" or "<1%", never "0%" next to a count of frames, and "%" never sits alone on a line. If "Hitches while chunks were loading" shows, it doesn't mention Sodium, and it ends "…otherwise lower the render distance yourself and compare sessions." A Sodium Chunk Updates suggestion may show separately, but only if Sodium's Chunk Updates (Video Settings → Performance) isn't already Deferred.

9. **Back in the Modrinth App.** Quit the game. In the instance's Content tab, press **Update all** (or check for updates).
   *Pass:* no "Couldn't prepare instance" or "Restore or repair mods/…" error. In `mods` (Open folder), there's no `fabric-26.2.jar` left by Distant Horizons' own updater.

10. **Send HQ.** Write one line per step: pass, or fail with what you saw (a phone photo of the screen helps).
    If anything failed, press **Open folder** in the app and zip these from the instance folder:
    - `logs\latest.log` (and `logs\debug.log` if it's there)
    - `crash-reports\` (if it exists)
    - `config\rigtune\` (it holds `history.json`, `pending.json`, `last-apply.json`, `helper.log`, `benchmarks.json`, `stutter.json` and `tryit.json`)
    Don't send the app's own screenshots: its window shows your account name.
    Then you can delete the throwaway instance.
