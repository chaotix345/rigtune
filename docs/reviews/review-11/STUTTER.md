## Checked, fine
- FixComparison: log-space binomial CDF (O(k), k <= MAX_N), upper tail via the complement's lower tail (no cancellation), MAX_N scaling, HALF_UP on the exact BigDecimal h/phi, zero-gameplay and zero-hitch guards (pLess = pMore = 1 -> SAME), LESS/MORE thresholds and the lost-ms condition as SPEC 5; `dispersion` pools within-side m2 only and clamps absurd values.
- SessionOutcome.plus: Chan's pooled mean/variance equals concatenating the bins; negative/non-finite values read as 0.
- FixTracker: sessions started before appliedAt, benchmark sources and STAGED-not-yet-APPLIED changes are ignored; excluded (around a benchmark), idle (RW-17) and < 120 s sessions are skipped before conditions; REVERTED -> undone even after COMPARED; a failed history read changes nothing (advanceAll); 5 skips / 14 days -> expired; extreme dates don't throw here.
- The before side's gate: benchmark source -> BENCHMARK; `aroundBenchmark` covers the session a benchmark ended and the one started after it; IDLE; LENGTH; one fix at a time; store writable; offers only for an analysis made in this run (a reloaded summary has no fixes).
- M4 ordering: `store().add` is queued on the io chain before `restartSession`'s save; appliedAt and startedAt are both truncated to the second; the ended before session is ignored as pre-apply.
- Threads: stutter-fixes.json only on the io chain or workers (StateStore synchronized); the render thread reads volatile caches; `adding` cleared in finally unless queued; `end()` keeps `fixAtStart` in a local (the queued save holds no Capture); `Fixes`/`Inputs` hold no capture; the specs cache holds the rules weakly; GcListener's collector survives stop, so end-of-session conditions keep it.
- Timed paths: no C20 work in `onFrame`; StutterHooks.tick adds a static-final read (`DevFixCalibration.ON`) and `StutterMonitor.idle()`; SettingsWatch's per-tick check (two cached ints, the overlay reference, the throttle every 10 ticks) allocates nothing.
- DevFixCalibration and DevStutter are inert without `-Drigtune.dev.stutterScript` (static finals checked first in `tick`, nothing registered); `StutterService.analysisProbe` is null outside the game test.
- Malformed stutter-fixes.json: type-checked decode, a future appliedAt / off-table from/to / unknown key skipped and never pruned, huge exponents read as defaults, corrupt -> .bad, newer -> read-only; prune loops bounded. (Except STUTTER-1.)
- Malformed stutter.json: null map values dropped (SD-5), `idleSeconds` NaN or <= 0 -> null, RW-10 percentages clamped (no long trimming loop), `clock()` safe for huge values, `windowSeconds()` guarded.
- Rules: LenientEntries drops unreadable/null stutterFixes entries alone; FixSpec re-validates (allowlist, value xor step, bounds); causeSpikesAtLeast is UNKNOWN for unknown/unmeasured causes and non-whole or negative numbers (also under `not`); a settingsChanged spike never counts as dominated.
- WS-S: L1 guard around every `StutterCapture.stop`; SD-3/SD-4 generation checks; SD-6 heap pools only; NEW-1 no MAJOR under generational Shenandoah; RW-11 event dating and window; RW-15's excluded step never starts or resumes the capture; the world-gen bucket's pause pairing for the benchmark capture; RW-18's `StutterStore.shown`.
